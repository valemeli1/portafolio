# Valeria Hernandez — Creative Developer Portfolio

An animated, responsive portfolio website in English showcasing projects in applied AI, mobile development, and workflow-focused software.

## Features

- Animated hero section and floating UI elements
- Scroll-triggered reveal transitions
- Responsive layouts for desktop and mobile
- Project cards linking to the original GitHub repositories
- Skills section and contact call to action
- Reduced-motion accessibility support
- Built with plain HTML, CSS, and JavaScript — no build step required

## Featured projects

- **GreenRack AI:** https://github.com/MarvinGL-2003/GreenRack-AI
- **Aircraft Maintenance Prototype:** https://github.com/valemeli1/prototipo-ddp
- **Vijosa Tickets:** https://github.com/JhonnatanPenate/vijosa-tickets

## Run locally

Open `index.html` in a browser. The page uses Google Fonts and remote Unsplash images, so those assets require an internet connection.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the public URL will appear in the Pages settings.

## Notes

The project-card images are illustrative stock imagery, not screenshots captured from the applications. Project descriptions summarize their intended focus; use each repository for the source code and implementation details.
